## 기록 규칙

1. 문제는 확인된 사실과 가설을 구분합니다.
2. 재현 조건에는 DB, fixture, 동시 요청 모델을 포함합니다.
3. 개선 전후는 같은 조건에서만 직접 비교합니다.
4. 수치에는 원본 명령, 테스트 또는 문서 링크를 연결합니다.
5. 로컬 fixture 결과의 적용 한계를 함께 기록합니다.
