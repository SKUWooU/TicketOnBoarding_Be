# Architecture Decision Records

ADR은 기술을 도입하거나 보류한 이유와 재검토 조건을 기록합니다. 구현한 기술을 나열하기 위한 문서가 아닙니다.

## 작성 조건

- 둘 이상의 유효한 대안이 있음
- transaction·일관성·운영 복잡도에 장기 영향을 줌
- 새로운 인프라 또는 외부 서비스를 도입하거나 명시적으로 보류함
- 이후 Issue에서 같은 결정을 반복 검토할 가능성이 있음

## 문서 형식

파일명은 `NNNN-short-title.md`를 사용합니다.

```markdown
# ADR-NNNN: 제목

## 상태
제안 / 승인 / 보류 / 대체

## 맥락과 재현 근거

## 결정

## 검토한 대안

## 결과와 trade-off

## 적용 범위와 한계

## 재검토 조건

## 관련 Issue·PR·측정
```

## 현재 상태

아직 승인된 ADR이 없습니다. 좌석 잠금, 집계 재고, 대기열, outbox와 메시지 브로커는 재현 근거가 생기기 전까지 BACKLOG 후보이며 ADR 결정으로 취급하지 않습니다.
